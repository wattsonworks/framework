Set the chart to the symbol & timeframe. Set the breaker to ON or OFF as the row lists. Leave everything else default — cascade off, no gates. That's the whole per-symbol treatment. Breaker ON only on AMAT, LRCX, ASML, NVDA, AXP; OFF everywhere else.

These are in-sample backtests; most trending names still trail buy-and-hold on raw return (AMAT daily is the exception — it beats it at half the drawdown). A disciplined, low-drawdown book — not a money printer.
